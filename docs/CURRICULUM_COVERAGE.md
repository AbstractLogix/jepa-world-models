## Learning path

1. Start with `01` for the concepts.
2. Use `02` and `03` to inspect small representation-learning experiments.
3. Use `05` and `06` to connect learned representations to planning.
4. Use `10` to compare planning horizons, feedback, and scripted reference subgoals. Use `04`, `07`, `08`, `11`, `12`, `14`, `15`, `16`, `17`, and `19` as optional analogues or local studies. Notebook `13` is an optional local transfer study. Its metrics do not establish the paper's COCO findings. Notebook `14` shows that low one-step intervention error can coexist with poor long-horizon planning on this task. Notebook `15` shows that preserved volume does not bound trajectory error. Notebook `17` checks uncertainty calibration and model-selected plan gaps in a state-based task. Notebook `19` uses hand-written summaries to explain top-down planning; it is not a learned hierarchy. Read each boundary above before treating its results as evidence about the cited research.
