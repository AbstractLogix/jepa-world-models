## Selection rule

Begin with the most feasible exact experiment, not the most impressive reported number. The first attempt used one LpWM/LeWM PushT configuration because the authors provide a public code repository, a reproduction-grid script, and identify the dataset. The paper states one training seed and three planning seeds, but does not name those seed values; the attempt used the official training default and reported chosen planning seeds as a local deviation. CPU training was OOM-killed before epoch 1, so this remains an incomplete attempt with no checkpoint or planner result. See the [attempt report](reproductions/lpwm-pusht.md).

Before implementation, create a Spec Kit feature for the selected paper result. Record the exact claim, original setup, local deviations, expected output, baseline, seeds, and stop conditions. Follow the [evaluation protocol](EVALUATION_PROTOCOL.md). Do not mark the paper-reproduction task complete until the raw local runs and conditions are recorded.

The current selected reproduction attempt is LeHami's generated actuated-pendulum comparison because its official data generator, split, configs, and probes are available locally. The user selected one full seed per model for this first pass; those runs measured 0.456258 rad/s for LeHami and 2.504686 rad/s for LeWM at K=0. A separate K=1-fitted rollout check measured both seed-0 curves through K=76. This is partial evidence; seeds 1 and 2 remain necessary for the paper's three-seed estimates. LeWAM Push-T remains a separate pending run; no archive or checkpoint was transferred. The point-cloud paper is a later candidate because its official evaluator requires a 24 GB CUDA GPU that is not available in the current local runtime.
