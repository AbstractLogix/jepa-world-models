# Research: JEPA Tutorial Priorities

**Reviewed**: 2026-10-15

This is a focused research snapshot for lesson planning. It is not a leaderboard. The summaries describe the cited papers' claims and settings, not results measured in this repository.

## JEPA-WAM reproduction candidate

The paper reports a 79.2% LIBERO-Plus average. The author README supplies a released-checkpoint command for the spatial suite, all categories, and one trial per task. The pinned classification contains 2,402 spatial variants. The released 40,000-step, batch-256 recipe differs from the paper's 60,000-step, batch-128 training, so the target is a checkpoint re-evaluation rather than a training reproduction. Feature 021's one-action smoke is complete: one task rendered, ten no-op warm-up steps ran, one policy action ran, and the task returned 0/1. This is pipeline evidence only. Keep the full suite pending because a first-task estimate suggests a long run. See the [diagnostic report](../../docs/reproductions/jepa-wam-libero-plus.md). Keep V-JEPA Policy and other JEPA-WAM-named papers separate.

## Alternatives considered

- **Call the current notebooks paper reproductions**: Rejected. The source shows toy data, CartPole, synthetic language targets, and reduced loss implementations.
- **Train a large video model as the first new lesson**: Rejected for now. It has high data and compute needs. Released checkpoint inspection gives learners a smaller first step.
- **Build every roadmap item in this change**: Rejected. The current request asks for the Spec Kit foundation, alignment, research, and roadmap. The lesson builds remain explicit open tasks under the long-term goal.

## Research limits

The sources include preprints and author-reported results. Publication status and source details may change. Recheck links, code, licenses, checkpoints, and data access before starting each lesson. This review did not confirm first-party VL-JEPA code or checkpoints. Notebook 11's local measurements use a different model stack and task and do not validate the paper findings. The planning-limits results are specific to the evaluated models and tasks; they are not a universal horizon bound.
