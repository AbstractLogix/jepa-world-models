# Quickstart: Decision-Usefulness Lesson

## Requirements

- Follow the repository setup in README.md.
- Install the existing general notebook dependencies. PyTorch is not required for this lesson.
- No external dataset, checkpoint, or robot hardware is needed.

## Run

1. Open notebooks/14_decision_usefulness.ipynb.
2. Run all cells from top to bottom.
3. Confirm that training, intervention, and evaluation seed groups are distinct.
4. Confirm that the notebook reports at least 60 intervention outcomes and 20 paired episodes per policy.
5. Review all raw episode outcomes and missing-run details before using summary values.

The notebook is an illustrative state-space experiment. It does not reproduce a cited paper or measure a JEPA representation.
