# Quickstart: H-JEPA Hierarchical Planning Lesson

1. Open [`notebooks/19_hjepa_hierarchical_planning.ipynb`](../../notebooks/19_hjepa_hierarchical_planning.ipynb) in Jupyter.
2. Select a Python 3.10–3.13 kernel.
3. Run all cells from top to bottom.

The notebook uses the Python standard library. It does not download assets, load a model, or run the H-JEPA evaluator. Its outputs are teaching examples only.
