# Quickstart: Policy-Noise Planning Tutorial

## Requirements

- Use the repository's existing Jupyter environment on CPU.
- No dataset, checkpoint, GPU, simulator, or new Python package is required.

## Run

1. Open [`notebooks/20_policy_noise_planning.ipynb`](../../notebooks/20_policy_noise_planning.ipynb).
2. Select a fresh Python kernel.
3. Run every cell from top to bottom.
4. Compare the generated per-seed summary with the scope and claim limits in [`docs/reproductions/policy-noise-planning.md`](../../docs/reproductions/policy-noise-planning.md).

The notebook uses fixed seeds. It regenerates a small toy evaluation in memory and does not write raw episode data to the repository.
